LzOS v1.0 开发日志
==============================

2026.8.22
  - 创建项目，完成了基本的框架与数字表达式的求值操作
  - 添加了逻辑表达式求值

2026.8.23
  - 解决了OS无法正确识别逻辑表达式是否合法的问题
  - 加入记忆模块，包括添加记忆、查看记忆和使用记忆

2026.8.30
  - 修复所有源文件中的中文乱码问题
  - 重构表达式求值引擎：
      · 提取 evaluateExpr() 递归求值函数，支持嵌套括号和一元运算符
      · 修复逻辑非运算符(~)的一元前缀运算符支持，禁止后缀用法
      · 修正逻辑运算符优先级：比较运算符(G/L/>/</=#) > 逻辑与(&) > 逻辑或(|)
      · 修复 >= (G) 和 <= (L) 运算符在 isExpression() 中的识别问题
      · 新增对 ! 运算符的预处理支持(转换为 ~)
  - 增强错误提示信息，使调试更方便
  - 修复Windows控制台中文乱码，启动时自动切换UTF-8编码
  - 添加位运算支持：&、|、^、~、<<、>>运算符
  - 添加变量存储与调用功能：var指令、变量引用、链式赋值
  - 添加常用数学函数：sqrt、abs、log、log10、log2、sin、cos、tan、
    asin、acos、atan、ceil、floor、round、exp、pow、max、min、cbrt、hypot
  - 修复checkExpression函数使用getline读取输入，支持函数参数中的逗号
  - 清理调试语句

==============================

【指令列表】
/e expression           数字表达式求值
/e tf expression        逻辑表达式求值
/e bw expression        位运算表达式求值
var name = expression   存储变量
mr+ /e expression       添加记忆
check mr                查看记忆模式
check var               查看所有变量
clear                   清空聊天记录
exit                    退出LzOS

【运算符列表】
  算术运算：+  -  *  /  ^(幂)
  关系运算：==(等于)  !=(不等于)  >  <  >=(G)  <=(L)
  逻辑运算：&&(与)  ||(或)  !/~(非)
  逻辑常量：true  false
  位运算：  &(按位与)  |(按位或)  ^(按位异或)  ~(按位取反)  <<(左移)  >>(右移)
  数学函数：sqrt  abs  log  log10  log2  sin  cos  tan  asin  acos  atan
             ceil  floor  round  exp  pow  max  min  cbrt  hypot

【示例】
  算术运算:  /e 1+1                  -> 2
  逻辑运算:  /e tf 1==1              -> true
  逻辑运算:  /e tf !0                -> true
  逻辑运算:  /e tf ~true             -> false
  逻辑运算:  /e tf 1&~0              -> true
  逻辑运算:  /e tf (true||false)&&true -> true
  位运算:    /e bw 5 & 3             -> 1
  位运算:    /e bw 5 | 3             -> 7
  位运算:    /e bw ~0                -> -1
  位运算:    /e bw 1 << 3            -> 8
  数学函数:  /e sqrt(16)             -> 4
  数学函数:  /e abs(-5)              -> 5
  数学函数:  /e pow(2,10)            -> 1024
  数学函数:  /e log10(100)           -> 2
  数学函数:  /e sin(0)               -> 0
  数学函数:  /e cos(0)               -> 1
  数学函数:  /e max(3,7)             -> 7
  数学函数:  /e min(3,7)             -> 3
  数学函数:  /e cbrt(27)             -> 3
  数学函数:  /e hypot(3,4)           -> 5
  嵌套调用:  /e sqrt(abs(-16))       -> 4
  嵌套调用:  /e pow(sqrt(4),3)       -> 8
  变量使用:  var x = 5               -> 存储变量x
  变量使用:  /e x + 3                -> 8
  链式引用:  var y = x * 2            -> 存储变量y
  记忆模式:  mr+ /e tf               -> 记忆逻辑模式
  记忆调用:  1==1                    -> true(使用记忆模式)
