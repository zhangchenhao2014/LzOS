---------------------------------------------------------------

指令：
/e expression 数字表达式的求值操作，expression必须为合法的中缀表达式，否则OS会返回报错
/e tf expression  逻辑表达式的求值操作，expression必须为合法的逻辑表达式，否则OS会返回报错
/e bw expression  位运算表达式的求值操作，expression必须为合法的位运算表达式，否则OS会返回报错
var name = expression 存储变量，例：var x = 5，变量可在后续表达式中直接使用
exit 退出LzOS
clear 清空聊天记录
mr+ 添加记忆，例：mr+ /e 1+1，此时若接下来再输入：1+1，则不会报错，而会输出2
check 查看任意参数，具体参数有列举表示

LzOS参数列表：
mr 当前记忆的模式
var 查看所有存储的变量

运算符列表：
  算术运算：+ - * / ^ (幂)
  关系运算：==(等于) !=(不等于) > < >=(G) <=(L)
  逻辑运算：&&(与) ||(或) !/~(非)
  逻辑常量：true false
  位运算：&(按位与) |(按位或) ^(按位异或) ~(按位取反) <<(左移) >>(右移)

示例：
/e 1+1              -> 2
/e tf 1==1          -> true
/e tf !0            -> true
/e tf ~true         -> false
/e tf 1&~0          -> true
/e tf (true||false)&&true -> true
/e bw 5 & 3         -> 1
/e bw 5 | 3         -> 7
/e bw ~0            -> -1
/e bw 1 << 3        -> 8
mr+ /e tf           -> 记忆逻辑模式
1==1                -> true（使用记忆模式）
var x = 5           -> 存储变量x
/e x + 3            -> 8（使用变量x）
var y = x * 2       -> 存储变量y，支持链式引用
check var           -> 查看所有变量
